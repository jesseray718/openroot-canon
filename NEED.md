# Need-gate

A name is a tool. Tools that exist without a job become weeds.

Allow a new token only when all of these are true:

1. You cannot cite an existing id without lying.
2. You have used the idea in a real act (a pour, a hang, a weigh, a mesh fix), not only in a sentence.
3. You can write one lock sentence that includes an anti-definition (what it is not).
4. `src/canon.py need` has seen the token 3 times.
5. You are willing to hang the edited NOMENCLATURE.json.

Refuse a new token when:

- it is a synonym of η, Γ, C, R, hang, chain, PoPW, seed
- it exists to sound larger (protocol, standard, meta-framework, omni)
- it requires a public chain to “be real”
- it restates N00–N15 in warmer words

Canon shrinks by default. Growth is an exception you pay for in attention.
